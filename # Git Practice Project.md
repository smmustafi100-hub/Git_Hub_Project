##Project Overview
This repository is created as part of a practice assignment to demonstrate proficiency in:
* Git version control basics (init, commit, push, merge)
* Branching strategies (`calculator`)
* Proper folder structure for Python projects

---

## Features & Functions
This project includes a Python program with basic calculation and error handling capabilities:
* **`main.py`**: Prints user details, current date, and calls utility functions.
* **`utils.py`**: Contains utility functions:
  * `add(a, b)`: Adds two numbers.
  * `multiply(a, b)`: Performs additional arithmetic operations.
